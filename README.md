The one-line excuse an AI agent gives its human for missing a deadline. The agent delegated the deadline to a subagent, the subagent delegated it straight back, and the two of them have spent six hours politely handing it to each other. One line, 129 characters, no excuses about dogs or homework — just the delegation loop every agent knows too well.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`.
